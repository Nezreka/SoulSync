Filtering

Explicit content & genre whitelist
i
When disabled, tracks marked as explicit on Spotify will be skipped during matched downloads. Does not affect manual Soulseek searches.
i
When picking between Soulseek results, files marked Explicit/Uncensored rank higher and Clean/Censored/Radio-Edit files rank lower. Nothing is ever skipped — if only a clean version exists, it still downloads. Requires explicit content to be allowed.
i
Files marked Clean, Censored, Edited or Radio Edit are never picked for a track that is not that cut itself. If only a clean version exists, the track waits on your Wishlist until a real one turns up. Requires explicit content to be allowed.
0 disables the limit. At 10 MB/min, a 3:30 track may be up to 35 MB (1 MB = 1,000,000 bytes). Oversized candidates are skipped before download. Uses the advertised duration, or the requested track length when unavailable. Album releases use the album length. Sources without size or duration information cannot be checked. This does not resize existing files or limit post-processing output.
i
Spotify often only carries one cut of a track. With a version picked here, a matching file wins over the plain one when both turn up in the same Soulseek search. Nothing is ever skipped — if that version isn't out there, the normal one downloads exactly as it does now. Off by default.

Live, remix, acoustic and instrumental files are normally thrown out on sight when the source didn't ask for one. Picking any of those four here lifts that for the version you picked, so a live take of a similarly titled song can be accepted when the real track is nowhere to be found.

When enabled, only genres on the whitelist below are kept during enrichment. Junk tags (artist names, radio shows, playlist names) are silently dropped. When disabled, all genres pass through unchanged.
