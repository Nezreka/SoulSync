Folder Paths

How files flow: Download Folder (raw downloads land here) → post-processing (tagging, artwork, organizing) → Music Library Folder (their final home — point your media server here). Keeping the two separate stops half-finished files being scanned.
Docker / Unraid detected: leave these as the container-internal paths and map your real folders in the container config — wrong values here break downloads.
Bare metal / Proxmox LXC / systemd: there is no container, so you're expected to unlock these and point them at your real folders.
⚠️ Your Music Library Folder is still the install-folder default. Every finished download is landing on the disk SoulSync is installed on — on a Proxmox LXC that's typically an 8 GB root that fills until the container hangs. Unlock the field and point it at your real music folder.

Additional Music Libraries

Your Music Library Folder above is already covered — you don't need to repeat it here. Add entries only for extra libraries SoulSync should read (a second collection, an archive drive), or when your media server sees the same files at a different path than SoulSync can. Used for tag writing, streaming, and file detection. Docker users: mount the extra folder(s) into the SoulSync container with read-write access, then add the container-side path here (e.g. /music2).

Sample Studio Folders

Where Sample Studio saves your chops — organized into Artist/Track folders inside the destination. The first folder is the default; the save dialog lets you pick a different one per chop (drums here, melodies there, a folder per project). Keep these outside your music library so your media server doesn't index chops as albums. Docker users: mount the folder(s) into the SoulSync container, then add the container-side path here.

Where downloads arrive

Files land in the download folder first, then get renamed and moved into the right library below. Each folder gets a live check under it: whether SoulSync can write there and how much room is left. Video folders are separate from your Music folders.
Docker / Unraid detected: these start on the container paths your compose file maps. Leave them and map your real folders in the container config. Unlock one only if you mapped it somewhere else.
Bare metal / Proxmox LXC / systemd: there is no container, so unlock each folder and point it at your real one.
Point this at the same folder as your slskd / torrent / usenet client. It's the same setting as the Music side's Download Folder, so it's locked here too: change it and Music changes with it.
Drop movie or episode files (or whole folders) here and they show on the Import page with the title SoulSync found. They're filed into your libraries with your naming template, exactly like a download. With the box ticked, a sure match is imported on its own once it has finished copying. Keep it apart from the download folder.

Libraries

Where finished downloads are filed. Point your Plex / Jellyfin / Emby libraries at the same folders.
New episodes of anime shows go here instead of the TV folder: shows in a TV library ticked Anime (Settings > Connections), shows set to Anime by hand, and shows not in your library yet that TMDB suggests are anime (an admin can change that on the show's page or when approving). Leave empty to keep anime with TV.

4K libraries (optional)

Keep 4K copies in their own folders, like a separate Movies 4K library in Plex. Off until you turn one on. A title files here when its quality profile is set to save to the 4K library (Settings > Quality). Titles you already have stay where they are, and their upgrades land beside the copy you have.
Anime keeps its own folder when one is set, whatever the profile.

More libraries

Your own movie and TV libraries, each with its own folder, like a Stand-Up, Documentaries or Kids library in Plex. A new title files into the library picked for it (in its Get or Manual search window), else the 4K one when its quality profile says so, else the first library whose rules match its genres or TMDB keywords, else the default library for its kind. Titles you already have stay where they are. The main and 4K libraries are here too: their folders are the ones above.

Your library's folders

Every folder your Plex / Jellyfin libraries read, Movies or TV. The ones SoulSync already reaches are ticked. Tell it where it reaches the rest and every file in them is found, renamed to your templates, recycled on delete and kept track of. New downloads still go to the folders above. Leave one blank and it works the way it does today.

Folders your server doesn't list

A collection SoulSync should manage that your server doesn't read. New downloads never go here.

Docker volumes

In Docker every folder above is a path inside the container. Each one needs a line in your compose file mapping a real folder to it, read-write so renames, upgrades and the recycle bin work. These are the lines for what's set here: swap the left side for the folder on your machine, then recreate the container.
