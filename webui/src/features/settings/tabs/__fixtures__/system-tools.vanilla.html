Inbound Request Endpoint

Trigger music downloads from external tools (Discord bots, Home Assistant, curl, etc.) using any API key above.
curl -X POST http://<host>:8008/api/v1/request \ -H "Authorization: Bearer <your-api-key>" \ -H "Content-Type: application/json" \ -d '{"query": "Artist - Track Name"}'
Returns a request_id for status polling. Add "notify_url" to POST results to a webhook on completion. Also triggers any Webhook Received automations in the Automation Hub.

MCP for AI Clients

Lets Claude and other AI apps search, check your library and download through SoulSync. Add http://<host>:8008/mcp as an MCP server and send an API key from above as a Bearer token. A read-only key can look but not change anything. Settings, keys and profiles are never reachable.

Lidarr Compatible API

Lets request apps that only talk to Lidarr (Singarr, MusicSeerr 1.x) use SoulSync instead. In the app, set the Lidarr URL to http://<host>:8008/lidarr and paste an Admin API key from above. Albums it asks for go on the wishlist of the profile below.
Pick a profile without download rights and every request waits for approval on the Requests page first.
