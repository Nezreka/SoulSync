i Variables: $author, $authorletter, $narrator, $title, $series, $seriespos (01), $year, $asin. Default: $author/$series/$seriespos - $title. Books with no series collapse the series folder and its number cleanly, the same way podcast season folders do. Use ${var} to append text.
i Deleting a book MOVES it to a hidden .deleted folder inside your audiobook library instead of erasing it, so a mis-click can be undone. The folder is hidden so Audiobookshelf, Plex and Jellyfin do not keep showing books you removed. Note the space is not freed until the bin is emptied. Off, deletes are permanent immediately.
days i How long a deleted book stays recoverable before the daily cleanup erases it for good. 0 turns the bin off — it does not mean "erase everything now", because purging on that reading would destroy what was recycled while the bin was still on. Default: 7

Audiobook Quality

What counts as a good file. One profile for every audiobook — the per-author card carries the settings that differ by author.
i Ranked first when several releases are otherwise equal; the rest keep their usual order behind it. M4B is the only format built for audiobooks — chapters, bookmarks, and one file instead of ninety. Pick MP3 if your player cannot read M4B. Format never outweighs having the right book and the right narrator.
i Releases in a format that is switched off are never shown or downloaded. Preferred Format only ranks, so with M4B preferred an MP3 is still grabbed when no M4B turns up; switch MP3 off here to wait for an M4B instead. A release whose format cannot be told from its title is still allowed. Switching every format off is the same as allowing them all.
i Whether a book should arrive as one file or as several smaller files, usually one per chapter. Switch one off and releases laid out that way are skipped; leave both on (or both off) for either. Only Soulseek says how many files a release has before it is downloaded; torrents and usenet do not, so they are always allowed.
kbps i Hides releases below this bitrate. 0 means no opinion. This is taste, and separate from the completeness floor above: that one asks whether a release could be the whole book at all, this one asks whether you want it. Audible's own files are 32 kbps mono and 64 kbps stereo, so 32 is a reasonable floor and anything above 128 is more than speech needs.
kbps i Hides releases above this bitrate, for when disk space matters more than headroom. 0 means no opinion. Speech gains nothing audible above about 128 kbps, so a 45-hour book at 240 kbps is roughly 4GB for no benefit.
i GraphicAudio and similar full-cast productions with music and sound effects. They are a different product from the audiobook — different cast, different running time, usually sold in several separately-downloaded parts. Left on they are shown but ranked below real readings and clearly labelled; turned off they are hidden entirely.

Downloads & Import

Books use the same torrent, usenet and Soulseek clients as music — set those up under Sources.
i Which Audible storefront the audiobook catalogue pages, author scans and follow checks query. Some titles are exclusive to one country's store, so picking the store you buy from finds books the US store never lists. Default: us
i Which sources a book search asks. Separate from the music chain on purpose — Tidal, Qobuz, HiFi and Deezer carry no audiobooks at all, so a book on the music chain would burn an attempt on each of them before it could succeed. The clients themselves are the same ones music uses; only the order and the category differ.
i The category SoulSync tags audiobook torrents and NZBs with in your download client. Keep it different from your music category so a finished book is never picked up by anything watching for music. Default: audiobooks
i Newznab category IDs searched for audiobooks. 3030 is the standard audiobook category and is deliberately kept OUT of music searches, so asking for it here costs the music side nothing. Only change this if your indexer uses a non-standard ID.
% i How much of the runtime Audible publishes has to actually be on disk before a book is filed into your library. A download client reports "complete" when the files it was asked for finished, which is not the same as the book being whole — and a book missing its last chapters plays perfectly until you run out of it. Short books are held in staging, never failed outright. Default: 92
days i How long an incomplete book is kept staged before it is failed and sent back to the wishlist. Torrents finish late and uploaders repair releases, so patience is right here; forever would mean one broken release holds a wishlist row for good. Default: 7
i Chapter files arrive named however the uploader left them. On by default: a book whose files sort wrong plays wrong. Turn this off only if you trust your releases' own numbering.
i Off by default: when a book arrives as many files, combine them into a single .m4b with one chapter marker per file during import. Needs ffmpeg on the server (the Docker image ships it). The originals are only removed after the merged file verifies, so a failed merge never loses the book.
i Off by default: a book that is downloaded or found in your library stays on the wishlist, marked "In library". Turn this on to drop it instead, the way the music wishlist does.
i Embeds title, author, series and narrator into each file on import. Narrator goes in the COMPOSER field, which is the convention every audiobook server settled on. Without this a book keeps whatever the uploader's ripper wrote, which is usually chapter 4 of a 27-hour book tagged as a track on an album called "audiobook".
i Embeds the cover into every chapter file. A cover the release already shipped is preferred over fetching one, so this still works offline.
i Writes cover.jpg into the book folder. Plex, Jellyfin, Audiobookshelf and Booksonic all read it from there.
i Writes metadata.opf (Audiobookshelf, Plex, Calibre) and book.nfo (Kodi, Jellyfin, Emby). Both, because the servers genuinely disagree about which to look for and they are a few hundred bytes each. These also carry the ASIN, which is what lets the daily library scan recognise a book you imported months ago.
