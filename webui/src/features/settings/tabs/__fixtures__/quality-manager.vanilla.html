What does this manage? i
Two things read a profile today: normal downloads/Wishlist items always follow the Default below, and Auto-Import can optionally use a different one instead (falls back to Default when unset). A profile's "Upgrade until" setting controls exactly how far below it counts as needing an upgrade — the Quality Upgrade Finder then actively searches for and proposes a replacement, while Quality Check only flags (you choose re-download/delete/ignore per finding); both read the cutoff live, same as the download pipeline. Per-artist/ album/track assignment is planned for the Library Manager; it will plug into this exact mechanism.
