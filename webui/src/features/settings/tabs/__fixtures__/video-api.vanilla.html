API Configuration

TMDB

Required ›
Get your free key from TMDB API Settings
Required. Primary movie & TV metadata source — nothing on the video side works without it.

TVDB

Required ›
Get your key from TheTVDB API
Required. TV series metadata — episodes & air dates the airing automations rely on.

OMDb (Ratings)

›
Get a free key from OMDb API
IMDb / Rotten Tomatoes / Metacritic ratings.

fanart.tv (Artwork)

›
Get a free key from fanart.tv
Clear logos, clearart, banners, posters & backgrounds (gap-fills missing art).

OpenSubtitles (Subtitles)

›
Get a free key from OpenSubtitles (register a consumer)
Subtitle downloads, plus which subtitle languages exist per title.

SubDL (Subtitles)

›
Get a free key from SubDL (account panel)

SubSource (Subtitles)

›
Get a free key from SubSource (profile page)

Trakt (Audience Rating)

›
Create a free API app at trakt.tv and paste its Client ID.
Adds Trakt's community audience score (and vote count) to movies & shows — and lets the Collection Studio build collections from public Trakt lists.

MDBList (List Collections)

›
Free key from mdblist.com (Preferences → API Access).
Lets the Collection Studio build collections from MDBList lists — the real IMDb Top 250, award lists (Oscar winners), and thousands of community lists.

Community Data (No Key)

›
Free community APIs — no key needed. Gap-fill extra data on your library in the background.

YouTube Extras (No Key)

›
Free community APIs — no key needed. Enrich cached YouTube videos in the background.
