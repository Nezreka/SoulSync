Import Lists

Auto-add movies & shows from a list
Everything on a list enters acquisition automatically (movies → wishlist, shows → follow with the chosen monitor policy). Only NEW list members are added, so removing something never boomerangs back. Synced by the "Sync Import Lists" automation. Ref: a TMDB list id, a chart key (trending_movies, top_shows, …), an IMDb ls-id/URL — Plex Watchlist needs no ref.
