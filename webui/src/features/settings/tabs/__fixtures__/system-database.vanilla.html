Tidy Up is safe to run any time: it drops old rows from caches and logs that keep their own retention (never listening history or library data), merges the search indexes and folds the write-ahead log back in. It also runs on its own with Cache Maintenance.
Compact Database rewrites the entire DB to reclaim unused space. Back up first. It needs free disk space about the size of the database and locks it while it runs, which on a very large library can take a long time.
Incremental Vacuum enables automatic page reclamation. Requires a one-time full compact to activate. After that, freed pages are reclaimed in small batches automatically.
