💡 Filesystem access — easiest setup ▾
Torrent and usenet clients write files to their own download folders, not Soulseek's. SoulSync needs read access to those folders to import the files. Simplest fix: point all your downloaders (Soulseek, qBittorrent, SABnzbd / NZBGet) at the same download folder. One folder, one path to worry about, everything just works.
  • Bare-metal: just set every client's download path to the same folder (e.g. your existing slskd folder). Done.
  • Docker: easiest is to reuse the ./downloads mount you already have for slskd — point qBit and SAB at /downloads inside their containers too. Or use the commented placeholders in docker-compose.yml if you want separate folders.
  • Remote client (NAS / different host): mount the remote folder locally (SMB / NFS / rclone) before SoulSync can see it.
