added this. watchlist, ⋯ menu, watchlist defaults, there's a new release status row with all seven musicbrainz statuses. turn off everything but official and that's your library wide filter.

per artist: open the artist on the watchlist, rules tab, release status, pick for this artist. same thing in the library under artist settings (turn off use the library's statuses). set it back to the default and it follows the library again.

a couple of things worth knowing:
- the status is on each release, not the album as a whole, so an album gets through if any of its releases has a status you kept on
- anything without a status (nothing set on musicbrainz, or from spotify/deezer/etc) always gets through, so nothing vanishes just because musicbrainz doesn't know it
- everything is on by default, nothing changes until you pick
- it covers new releases the watchlist finds and the missing releases the discography refresh reports
